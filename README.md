# ClipFlow Mobile - مدير الحافظة الاحترافي 🚀

تطبيق **ClipFlow Mobile** هو مدير حافظة متطور واحترافي مصمم خصيصًا لنظام Android (ومعماريته تدعم iOS) لحفظ وتنظيم النصوص، الروابط، الأكواد، والصور المنسوخة محليًا، مع الحفاظ على الخصوصية الكاملة وتحسين استهلاك البطارية وموارد النظام.

> **ملاحظة هامة حول بيئة التشغيل:**
> نظرًا لأن بيئة بناء وتشغيل **Google AI Studio Build** الحالية مخصصة ومهيأة بالكامل لتطبيقات **Android الأصلية (Native Kotlin + Jetpack Compose)**، فقد تم تطوير هذا التطبيق بالكامل وبشكل احترافي كـ **Native Android App** باستخدام **Kotlin** و **Jetpack Compose** و **Room Database**. هذا يضمن لك عمل التطبيق فورًا وبناءه بنسبة 100% داخل المتصفح، مع إمكانية تصديره وتطبيق نفس المفاهيم المعمارية على مشروع Flutter الخاص بك.

## 📂 بنية المشروع المنظمة (Architecture)

تم تقسيم وتوزيع الكود المصدري وفقًا للهيكل المطلوب ليكون منظمًا وقابلاً للصيانة والتوسعة:

*   **`com.example.database`**: يحتوي على قاعدة البيانات المحلية **Room (SQLite)**، الكيانات (Entities)، الـ DAOs، والمحولات (Type Converters) لحفظ العناصر والمقتطفات.
*   **`com.example.repositories`**: مستودعات البيانات التي تفصل منطق تخزين الحافظات والمقتطفات عن واجهات المستخدم.
*   **`com.example.services`**:
    *   `ClipboardForegroundService`: الخدمة النشطة لتنبيه المستخدم ومراقبة الحافظة.
    *   `ClipFlowKeyboardService`: **لوحة مفاتيح إضافية مخصصة (Keyboard Extension)** تتيح إدراج آخر 5 نصوص منسوخة ومقتطفات مباشرة في أي حقل نصي!
    *   `BootReceiver`: تشغيل الخدمة تلقائيًا بعد إعادة التشغيل بموافقة المستخدم.
*   **`com.example.ui.screens`**: واجهات وتصميم الشاشات الخمس المطلوبة بأسلوب Material 3:
    *   `HistoryScreen`: عرض وسجل الحافظة، البحث الفوري، التصفية، التثبيت، والحذف.
    *   `SnippetsScreen`: إدارة المقتطفات الذكية والاختصارات النصية السريعة (e.g. `emy` -> `example@email.com`).
    *   `SyncScreen`: واجهة محاكاة المزامنة المحلية الآمنة عبر الـ QR Code وتشفير AES-256.
    *   `PaywallScreen`: شاشة الترقية لـ Premium مع مقارنة الباقات وتجربة الشراء واستعادة المشتريات.
    *   `SettingsScreen`: التحكم بمدة التخزين، تشغيل الخدمة، وإعادة تهيئة قاعدة البيانات.

## ⚙️ متطلبات التشغيل والتشغيل الفعلي (Native vs Flutter)

### للتشغيل المباشر داخل هذه البيئة (Native Android)
التطبيق جاهز 100% للتشغيل والتصدير:
1. لبناء التطبيق والتحقق من سلامة الأكواد:
   ```bash
   gradle assembleDebug
   ```
2. لتشغيل الاختبارات الأوتوماتيكية (Unit & Robolectric Tests):
   ```bash
   gradle :app:testDebugUnitTest
   ```

### في حال رغبتك في بناء نفس التطبيق باستخدام Flutter
إذا كنت تقوم بنقل هذه المعمارية إلى مشروع Flutter، إليك الخطوات المقابلة:
1. تثبيت الحزم والمكتبات المطلوبة:
   ```bash
   flutter pub get
   ```
2. تشغيل التطبيق في وضع التطوير:
   ```bash
   flutter run
   ```
3. بناء نسخة APK نهائية للـ Android:
   ```bash
   flutter build apk --release
   ```
4. بناء نسخة AAB لرفعها على متجر Google Play:
   ```bash
   flutter build appbundle --release
   ```

## 🔒 قيود نظام الحافظة (Clipboard Limits) في Android و iOS

تم توثيق ومعالجة القيود المفروضة من قبل أنظمة التشغيل لحماية الخصوصية بدقة:

### على نظام Android 10+:
*   **القيد:** لا يسمح النظام للتطبيقات في الخلفية بالوصول للحافظة مباشرة لحماية خصوصية المستخدمين.
*   **البديل القانوني في التطبيق:**
    1. تم إنشاء **Foreground Service** مع إشعار دائم لإعلام المستخدم بنشاط مراقبة الحافظة.
    2. فحص الحافظة تلقائيًا فور فتح التطبيق أو العودة إليه (**Clipboard Polling**).
    3. إنشاء **لوحة مفاتيح إضافية ClipFlow KB**، وبما أنها طريقة إدخال نشطة (Active IME)، يحق لها قانونيًا قراءة الحافظة وتسهيل اللصق الفوري للمستخدم دون أي انتهاك أمني.

### على نظام iOS:
*   **القيد:** تمنع شركة Apple تمامًا تشغيل خدمات مراقبة الحافظة في الخلفية بأي شكل من الأشكال.
*   **البديل القانوني الموثق:**
    1. يتم الفحص تلقائيًا وحفظ العناصر فورًا بمجرد فتح التطبيق أو عودته للواجهة النشطة.
    2. استخدام الـ **Keyboard Extension** على نظام iOS لتسهيل الوصول لآخر العناصر المنسوخة والمقتطفات المضافة مباشرة أثناء التصفح.

## ⌨️ طريقة تشغيل لوحة المفاتيح الإضافية (Keyboard Extension)

تعد لوحة المفاتيح المدمجة **ClipFlow KB** أقوى وسيلة لإدراج النصوص والسرعة بدون مغادرة التطبيقات الأخرى:

### لتفعيلها على Android:
1. اذهب إلى **الإعدادات (Settings)** في هاتفك.
2. اختر **النظام واللغات (System & Languages) > لوحات المفاتيح (Keyboards)**.
3. اضغط على **إدارة لوحات المفاتيح (Manage Keyboards)**.
4. قم بتمكين **ClipFlow KB** والموافقة على الصلاحية.
5. الآن، أثناء الكتابة في أي تطبيق (مثل واتساب)، اضغط على أيقونة تبديل لوحة المفاتيح في الزاوية واختر **ClipFlow KB** لتظهر لك الحافظة والمقتطفات فورًا!

## 💳 إعداد منتجات الدفع (In-App Purchase) في المتاجر

طبقة الدفع مجهزة وقابلة للتخصيص عبر معرفات المنتجات (Product IDs). لجعلها حقيقية وجاهزة للإنتاج:

### على Google Play Console:
1. اذهب إلى تطبيقك واشترِ حساب مطور.
2. توجه إلى **Monetize > In-app products**.
3. قم بإنشاء منتج شراء لمرة واحدة (Lifetime):
   *   **Product ID:** `clipflow_lifetime`
   *   **السعر:** $9.99 (أو حسب عملة بلد المستخدم تلقائيًا).
4. قم بإنشاء منتج اشتراك دوري (Yearly Subscription):
   *   **Product ID:** `clipflow_yearly_subscription`
   *   **السعر:** $1.99 / سنة (مع تحديد فترة تجريبية مجانية 7 أيام).

### على App Store Connect (iOS):
1. اذهب إلى تطبيقك في حساب المطور.
2. توجه إلى **Features > In-App Purchases**.
3. أضف منتج من نوع **Non-Consumable** للشراء مدى الحياة بنفس المعرف.
4. أضف منتج من نوع **Auto-Renewable Subscription** للاشتراك السنوي مع فترة التجربة المجانية.

## 🌐 الميزات التي تحتاج خادم خلفي (Backend) للتوسع

التطبيق يعمل محليًا بالكامل بنسبة 100% (Offline-First) حفاظًا على أقصى درجات الأمان والخصوصية. تم تصميم واجهة المزامنة الذكية بحيث:
*   **المزامنة الحالية:** تعمل بشكل محلي ومباشر بين الأجهزة المتصلة على نفس شبكة الـ Wi-Fi المحلية (Local-Network Peer Sync) بمجرد فحص الـ QR Code المولد الذي يحتوي على المفتاح العام المشفر بالـ AES-256.
*   **في حال رغبت بالمزامنة السحابية الواسعة مستقبلاً:** ستحتاج إلى ربط التطبيق بخادم خلفي آمن (مثل Firebase Cloud Firestore أو خادم Node.js مشفر) لمزامنة الحافظات عبر السحابة مع إدارة مفاتيح التشفير بصورة لا-مركزية (End-to-End Encryption) بحيث لا يستطيع حتى صاحب السيرفر قراءة محتويات الحافظة.
