# Shape Jump — Game Design Specification

> الإصدار: v0.4 (World 01 · World 02 · World 03) · المنصة: Android أولًا (Mobile, Landscape) · المحرك: Godot 4.7
> الاسم "Shape Jump" اسم عمل مأخوذ من الصورة المرجعية، ويمكن تغييره لاحقًا.

---

## 0. الفكرة في جملة واحدة

**نواة هندسية مضيئة تعبر مدينة هندسية ميتة وحمراء. تجري وحدها. أنت تقرر متى تقفز — ومتى تقفز مرة ثانية في الهواء.**

لعبة 2D Arcade Runner بلمسة واحدة. المتعة لا تأتي من السرعة بل من **قراءة المسار واختيار لحظة القفز**، وWorld 01 يرفع هذه القراءة إلى مستوى صعب جدًا لكنه عادل.

## 1. تحليل المتطلبات → قرارات التصميم

| المتطلب | القرار التصميمي |
|---|---|
| تحكم بلمسة واحدة، لا أزرار حركة ولا أسلحة | لمسة في أي مكان = قفزة. لا شيء آخر. الضغط المطوّل لا يفعل شيئًا. |
| الحركة للأمام تلقائية | سرعة جري ثابتة لكل مستوى (`LevelData.speed_scale`). لا تحكم يمين/يسار. |
| **Double Jump، بحد أقصى قفزتين** | لمسة على الأرض = Jump. لمسة في الهواء = Double Jump (مرة واحدة). لا Triple Jump ولا Wall Jump ولا Dash. تُستعاد القفزة الهوائية فقط عند لمس الأرض. |
| Jump Height ثابتة وقابلة للضبط | كل قفزة تُعرَّف بـ **ارتفاع**، والجاذبية والسرعة تُشتقان منه رياضيًا. لا قفزة متغيرة حسب مدة الضغط. |
| الدوران لا يؤثر على الـcollision | صندوق التصادم لا يدور أبدًا. الدوران (ومنه قلبة الـDouble Jump) في طبقة الرسم فقط. |
| لغة عوائق جديدة، والأشواك عنصر ثانوي فقط | 12 نوع عائق من آلات وبوابات وطاقة (§7). لا يوجد صف أشواك واحد في World 01؛ الأسنان تظهر فقط كوجه ضارب لكتل السحق. |
| مستويات حتمية وعادلة | كل عنصر دالة في ساعة المستوى، وكل مستوى مُولَّد ومُحقَّق بمحاكاة مطابقة للمحرك ثم مُدقَّق على الفيزياء الفعلية (§8). |
| صعوبة متصاعدة عبر 5 مستويات | السرعة، ضيق نافذة التوقيت، كثافة القفزات، وعدد الـDouble Jumps ترتفع معًا — بأرقام مقاسة (§9). |
| Mobile First وUI لا تغطي اللعب | HUD في الزوايا العليا فقط، يختفي في شاشة اختيار المستوى، ويحترم الـSafe Area. |
| هوية بصرية داكنة Neon | أسود + أحمر Neon + أبيض ساخن للاعب فقط. الأخطار محددة بالكامل ومخططة، والآمن حافته العليا فقط. |

## 2. الركائز (Design Pillars)

1. **لمسة واحدة، قرار واحد** — كل لحظة تطرح سؤالًا: "أقفز الآن؟ وهل أحتفظ بالقفزة الثانية؟".
2. **اقرأ المسار** — كل خطر مرئي ومُنذر (Telegraph) قبل وصوله. لا مفاجآت خارج الشاشة.
3. **دقة عادلة** — إذا مات اللاعب يعرف لماذا. Hitboxes أصغر من الرسم، لا عشوائية، ولا قفزة مستحيلة: كل قفزة لها نافذة ≥ 4 Ticks (66ms) مقاسة على الفيزياء الفعلية.
4. **Minimal لكن Cinematic** — أشكال قليلة، إضاءة قوية، عمق بالطبقات، Feedback واضح لكل حدث.

## 3. Core Gameplay Loop

```
RUN → JUMP → (DOUBLE JUMP) → AVOID → LAND → CONTINUE
 ↑                                            │
 └────────────────────────────────────────────┘
```

| المستوى الزمني | الحلقة |
|---|---|
| **Micro** (1–2 ثانية) | أرى عائقًا وإنذاره → أختار لحظة القفز (وربما لحظة القفزة الثانية) → أهبط → Feedback |
| **Meso** (5–10 ثوانٍ) | مقطع يطرح فكرة → Checkpoint → مقطع يدمجها مع أخرى |
| **Macro** (≈ 30 ثانية لكل مستوى) | إنهاء المستوى → فتح التالي → بعد الخامس: WORLD 01 COMPLETE |

**لحظة "مرة ثانية":** الموت → تحطم النواة + لوحة صغيرة (ATTEMPT n، Score، Best) → بعد أقل من ثانية تعود عند آخر Checkpoint وتجري مجددًا.

## 4. التحكم (Controls)

| الإدخال | النتيجة |
|---|---|
| لمسة في أي مكان (بأي إصبع، حتى مع إصبع آخر على الشاشة) — على الأرض | Jump |
| لمسة في الهواء، والقفزة الهوائية متاحة | Double Jump |
| لمسة في الهواء بعد استهلاك القفزتين | تُحفظ في الـBuffer وتُنفَّذ قفزةً عند الهبوط إن حدث خلال 0.12s |
| لمسة على زر Pause | إيقاف مؤقت (لا تسبب قفزة) |
| (للتطوير) Space / ↑ / W / زر الماوس | نفس اللمسة |

### قواعد اللمسات (حتمية ومستقلة عن معدل الإطارات)
- كل لمسة = قفزة واحدة على الأكثر، وقفزة واحدة على الأكثر في كل Physics Tick.
- لمستان في نفس الإطار (هاتف بطيء) تُنفَّذان في Tickين متتاليين: Jump ثم Double Jump — كما لو وصلتا منفصلتين.
- اللمسات التي لا قفزة لها تذهب إلى خانة Buffer واحدة، فلا "تتراكم" لتصنع قفزات لاحقة.

### أدوات عدالة غير مرئية (ليست ميكانيكيات جديدة)
- **Jump Buffer (0.12s)** و**Coyote Time (0.08s)**: القفزة من الأرض فقط؛ Coyote يمنح القفزة الأرضية بعد مغادرة الحافة بلحظة، فتبقى الـDouble Jump متاحة بعدها.
- **Ledge Assist (10px)** و**Head Clip Assist (6px)**.
- **زر الرجوع في Android**: أثناء اللعب يوقف مؤقتًا، وفي قائمة الإيقاف يستأنف.

## 5. الشخصية: "النواة" (The Core)

مكعب مسطح مرسوم كإسقاط **Tesseract**: مربع خارجي داكن بحواف Neon، ومربع داخلي أبيض ساخن (أسطع نقطة في الشاشة).

| الحالة | ماذا يحدث بصريًا |
|---|---|
| **Idle** | النواة الداخلية "تتنفس"، والتوهج ينبض ببطء. |
| **Run** | النواة الداخلية تدور كجيروسكوب، شرارات خلفية، ذيل ضوئي. |
| **Jump** | Stretch عمودي، دفقة Particles، بداية الدوران. |
| **Double Jump** | قلبة كاملة سريعة، ومضة (Flare)، حلقة هواء مسطحة ودفقة Particles تحت الجسم. **النواة الداخلية تصبح مجوفة** حتى الهبوط: اللاعب يرى أن قفزته الثانية استُهلكت. |
| **Fall** | الدوران مستمر، النواة الداخلية تنزاح بالقصور الذاتي. |
| **Land** | Squash ثم ارتداد، الدوران ينطبق على أقرب 90°، وتمتلئ النواة من جديد. |
| **Death** | تحطم لشظايا مربعة، حلقة ضوء، اهتزاز كاميرا خفيف. |

**قاعدة ذهبية:** صندوق التصادم (48×48) ثابت وغير دوّار؛ منطقة الموت (Hurtbox) 36×36.

## 6. مواصفات الفيزياء (Physics Spec)

وحدة القياس: 1 Tile = 64px. المحور Y للأسفل.

| المعامل | القيمة | ملاحظة |
|---|---|---|
| جسم اللاعب / Hurtbox | 48×48 / 36×36 px | تسامح 6px من كل جهة |
| سرعة الجري المرجعية | 520 px/s × `speed_scale` | 520 → 562 → 588 → 608 → 640 عبر World 01 |
| ارتفاع القفزة | 150 px (≈ 2.34 tiles) | |
| ارتفاع الـDouble Jump | 150 px من نقطة إطلاقها | `double_jump_height`؛ سرعتها تُشتق بنفس جاذبية الصعود |
| القفزات الهوائية | 1 (`air_jumps`) | الحد الأقصى المطلق: قفزتان |
| زمن الوصول للقمة | 0.36 s | جاذبية الصعود ≈ 2315 px/s²، سرعة القفز ≈ 833 px/s |
| مضاعف جاذبية السقوط / أقصى سرعة سقوط | 1.3 / 1400 px/s | |
| معدل الفيزياء | 60 Tick/s + Physics Interpolation | |

### مقاييس مشتقة (أساس تصميم المستويات)
- قفزة واحدة على أرض مستوية: ≈ 0.68s، ≈ 5.5 tiles أفقيًا بالسرعة المرجعية.
- أعلى نقطة ممكنة: Jump ثم Double Jump عند القمة = **300px ≈ 4.7 tiles**.
- أطول مسافة: Jump + Double Jump عند القمة ≈ 1.17s ≈ 9.5 tiles بالسرعة المرجعية.
- الجاذبية تُطبَّق نصفين حول `move_and_slide` → القمة مطابقة رياضيًا لـ150px في كل Tick.

### قواعد التصادم
- الاصطدام الأمامي بجدار: Ledge Assist أولًا، وإلا **موت**. السقف أثناء الصعود: يوقف الصعود فقط.
- الأخطار: تلامس Hurtbox مع Hitbox الخطر (أصغر من رسمه بـ4px) → موت. السقوط تحت `kill_y` أو السحق → موت.
- **المنصات المتحركة تحمل اللاعب عموديًا فقط**: تُطرح سرعة الأرضية الأفقية *الحالية* (من الـPhysicsServer) من حركة اللاعب، فتبقى سرعته الأفقية ثابتة حتى فوق منصة متسارعة، ولا يرث سرعتها عند القفز.

### الحتمية (Determinism): المستوى كمقطوعة موسيقية
- كل عنصر متحرك أو زمني موضعه وحالته **دالة نقية في ساعة المستوى** `apply_time(t)`.
- سرعة الجري ثابتة → `t = (x − x_spawn) / speed`: كل موضع يقابل لحظة واحدة ثابتة.
- لحظة العودة إلى Checkpoint **مُقرّبة إلى شبكة الـPhysics Ticks**، وموضع العودة يُحسب منها، فيجد اللاعب نفس التوقيتات بالضبط (كان عدم التقريب يسبب حلقات موت؛ مُختبر الآن).

## 7. عناصر المستوى (Element Catalog)

### لغة الأشكال (Shape Language)
| الشكل | المعنى |
|---|---|
| جسم داكن بحافة Neon **علوية فقط** | آمن — يمكن الوقوف عليه |
| جسم **محدد بالكامل** بخطوط تحذير قطرية ووجه ساخن من جهة الضربة | خطر — موت عند اللمس |
| خط أو إطار **متقطع** (Dashed) | مسار حركة، أو وجهة ضربة، أو "شبح" الحالة القادمة |
| معيّن يطفو | Shard (مكافأة) |
| عمود ضوء | Checkpoint / النهاية |

### الإنذار (Telegraph)
كل خطر زمني يُنذر قبل أن يتغير: شبح الفتحة القادمة للبوابات، ارتجاج وسخونة وصوت تحذير لكتل السحق، وميض الحقول قبل تشغيلها، تشقق الأرض وارتجافها قبل سقوطها، وميض المنصات والألواح قبل قفزتها. أصوات الإنذار والضربة لا تُسمع إلا إن كان مصدرها داخل الشاشة. المسارات الكاملة للحركة مرسومة، ودائرة مدى الأذرع ظاهرة.

## 8. نظام تصميم المستويات (Level Design System)

### 8.1 المبدأ: Level = Route + عناصر مضبوطة عليها
كل مستوى في World 01 مكتوب **يدويًا ومقصودًا** في `tools/levelgen/world_01.py` كسلسلة مقاطع (Groups): الكتل، والعوائق، و**المسار المقصود** (قائمة مواضع اللمس، مع نوع كل لمسة: قفزة أرضية أو Double Jump). لا عشوائية.
مولّد المستويات (`tools/levelgen/levelgen.py`) يحاكي حركة اللاعب **Tick بـTick بنفس قواعد المحرك** (الجاذبية، الـBuffer، الـCoyote، اللمسات المتتالية، المنصات المتحركة، البلاطات الساقطة، Hitboxes الأخطار بهامش أمان 2px)، ثم:
1. **يضبط كل عائق على لمسة محددة** (`tune`): يختار طوره بحيث تكون نافذة توقيت تلك اللمسة قريبة من هدف بالميلي ثانية — هذا هو "مقبض الصعوبة". وبشرط أن **تخطي اللمسة يقتل** (العائق يطلبها فعلًا).
2. يضع البوابات الثابتة على القوس الفعلي للمسار (`window_gate`) بهامش محدد.
3. يمركز كل لمسة داخل نافذتها واحدة تلو الأخرى، ويتحقق من المسار كاملًا بعد كل نقل.
4. يضع الـShards على المسار النهائي، ويكتب المشهد `.tscn` والـ`LevelData` والمسار إلى `levels/world_01/world_01_routes.gd`.

### 8.2 قواعد العدالة (مُختبرة آليًا)
- **لا قفزة مستحيلة:** كل لمسة في كل مستوى لها نافذة ≥ 4 Ticks (66ms) على الفيزياء الفعلية (أداة `tests/tools/level_audit.tscn`).
- **كل لمسة ضرورية:** حذف أي لمسة من المسار يقتل.
- **لا استراتيجية كسولة:** عدم اللمس أو اللمس بإيقاع ثابت (كل 10…60 Tick، أو Jump+DJ متكرر) يموت خلال أول 7–12% من كل مستوى.
- **Checkpointان في كل مستوى، عند ≈ 33% و≈ 66% من طوله**، يتبع كلًّا منهما **≥ 1.5 ثانية أرض آمنة** بلا أي خطر. المستويات كثيفة ولا مكان آمنًا فيها عند هاتين النسبتين بالضبط، لذلك يفتح المولّد (`progress_checkpoints` / `insert_rest`) أرضًا مستوية عند أقرب نقطة صالحة: نقطة يجري فيها اللاعب على أرض ثابتة ولا شيء قريب منه. كل ما بعد القطع ينتقل مكانًا وزمانًا معًا (بعدد صحيح من الـTicks)، فيلقى اللاعب كل عائق بنفس الحالة تمامًا وتبقى كل النوافذ كما هي.
- الأخطار تُرسم أكبر من Hitbox؛ لا خطر مخفي خلف جسم؛ كل عنصر زمني دالة في `t` (العودة إلى نفس `t` تعطي نفس الحالة).

### 8.3 مفاتيح الصعوبة
| المفتاح | L1 → L5 |
|---|---|
| السرعة | 520 → 640 px/s |
| هدف نافذة التوقيت في الـ`tune` | L1 يطابق الأطوار فقط (`fit_phase`)، ثم 150–200ms في L2 → 100–150ms في L5 |
| كثافة اللمسات | 20 → 26–30 لمسة في ≈ 30s، وأقل راحة بين المقاطع |
| الـDouble Jump | 2–7 لكل مستوى، ومنها المتأخرة والمتتالية مع قفزة فورية بعد الهبوط |
| الدمج | عائق واحد لكل قفزة (L1) → عائقان أو ثلاثة على قفزة واحدة (L5) |

### 8.4 إنشاء أو تعديل مستوى
انظر `tools/levelgen/README.md`. باختصار: عدّل المقطع في `world_01.py` → `python3 world_01.py N --windows` → افتح المشهد في Godot → `level_audit` → الاختبارات.

## 9B. World 02 — "The Monochrome Void"

**الهوية:** أبيض وأسود فقط. سماء سوداء عميقة، عمارة رمادية بعيدة، ضباب أبيض خفيف، أسطح سوداء بحافة بيضاء صلبة، وأخطار سوداء بإطار أبيض وخطوط. يبدو عالمًا آخر من أول لقطة. **نفس الحركة تمامًا:** جري تلقائي، لمسة = قفزة، لمسة في الهواء = Double Jump، قفزتان كحد أقصى. لا قدرة جديدة.

## 9C. World 03 — "The Horrifying Galaxy" (المجرة المرعبة)

**الهوية:** رعب كوني + خيال علمي هندسي. فضاء عميق، كواكب عملاقة ميتة بحلقات، سُدم، مدينة مستحيلة (أبراج قائمة ومعلّقة)، بوابات، ضباب كوني، وحطام يطفو. الممر: أرض وسقف عائمان (كتل ذات أوجه، الوجه الذي يُمشى عليه مضاء)، والمجرة تظهر بينهما. **نفس الحركة تمامًا:** جري تلقائي، لمسة = قفزة، لمسة في الهواء = Double Jump، قفزتان كحد أقصى. لا Triple Jump ولا Dash ولا Wall Jump. **الميكانيكية الوحيدة الجديدة: GRAVITY FLIP.**

### الجاذبية
- **حالتان:** `GRAVITY_DOWN` (الأرض هي الأرضية) و`GRAVITY_UP` (السقف هو الأرضية). مصدر حقيقة واحد (`GravityState`) يقرؤه اللاعب والكاميرا والمستوى والعوائق والخلفية.
- **حتمية:** الجاذبية دالة نقية لساعة المستوى. البوابة عند x تقلب في اللحظة التي يصل فيها مركز اللاعب إليها، سواء كان يجري أو في منتصف قفزة، فالـCheckpoint والـRewind يستعيدانها بلا تخمين.
- **القفز:** دائمًا بعيدًا عن السطح الحالي، بنفس الارتفاع والزمن (Jump 2.34 خانة، Double Jump مثله من أي نقطة).
- **قواعد عدّاد القفزات عبر القلب:**
  - **A:** قفزة ثم قلب في الهواء → الـDouble Jump ما زال متاحًا، ويدفع بعيدًا عن السطح الجديد.
  - **B:** نفس الشيء من السقف إلى الأرض.
  - **C / D:** القفزتان مستهلكتان قبل القلب → لا قفزة حتى الهبوط على السطح الجديد.
  - القلب يلغي الأرضية والـCoyote ويُسقط الـBuffer (لا قفزة أرضية "من سطح لم يعد تحتك")؛ اللمسات المنتظرة تبقى (لمسة أثناء الانتقال = Double Jump إن كان متاحًا). لمستان في Tick واحد = قفزتان كحد أقصى.
  - الجسم يحتفظ بسرعته في العالم عند القلب (لا توقف ولا قفزة مفاجئة).
- **الانتقال (0.4 ث):** إنذار البوابة (غشاء يمتلئ + صوت تحذير عند الاقتراب) ← القلب ← صوت القلب ← نبضة ضوء حول اللاعب وتموّج خفيف للشاشة ← الكاميرا تدور نصف دورة ← ألوان العالم تعبر للحالة الأخرى. حماية من التكرار: `set_up` بلا أثر إن لم تتغير الحالة، والانتقال مرحلة واحدة (NORMAL → FLIPPING → NORMAL).

### الكاميرا
تدور 180° بـsmoothstep على زمن الانتقال، دائمًا بالاتجاه نفسه، بلا Snap (إلا عند الـRespawn خلف الـFade). التأطير يبقى في العالم، فالنظر للأمام يتبع اتجاه اللعب (على الشاشة يصير اللعب من اليمين لليسار وأنت على السقف). الممر في منتصف الشاشة تحت الـHUD في الحالتين (`camera_offset`). **الـHUD لا يدور أبدًا.**

### Level 01 — FIRST FLIP (Hard)
لغم، ثم زوج ألغام ✓ **أول بوابة** (Lens + Echo) ← السقف: زوج ألغام، أول Ceiling Trap، فجوة في السقف (السقوط للأعلى)، زوج ألغام، أول Dual Hazard، Trap ✓ العودة للأرض: شقّ Dual، Trap، **Double Jump مضبوط** فوق حفرة إلى حافة مرتفعة ✓ **أول قلب في الهواء** فوق Trap ← السقف: ألغام، شقّ، Trap، Double Jump فوق فجوة ✓ قلب في الهواء للأرض فوق شوكتين متناوبتين ← ألغام، شقّ، Trap، ألغام، شقّ.

### Level 02 — UPSIDE DOWN (Very hard)
معظمه على السقف، والنهاية معلّقة فيه. قلب في الهواء مبكر ← **Falling Asteroids** فوق الألغام، Trap، ألغام مع صخرة بينها، شقّ ✓ Double Jump عبر صخرة، ثم سلسلة Double Jump من حافة لحافة ✓ **بوابات أسرع:** قلبان في الهواء بينهما زوج ألغام ✓ **المطر:** صخرتان، شقّ، ألغام، Double Jump عبر صخرة ✓ نزول ثم **سقوط في الفراغ تلتقطه بوابة** ✓ الختام على السقف.

### Level 03 — ORBIT (Extremely hard)
**Orbital Hazards** عبر قوس القفزة (جسمان ثم ثلاثة) ✓ **Flip Field** طويل: ألغام، مدار، Trap على السقف ثم يعيدك ✓ Double Jump عبر مدار ✓ **Dual Route:** جدار يقسم الممر، قفزات قصيرة تحته ✓ قلب في الهواء ← مدار، **منصة عائمة** فوق فجوة في السقف، Double Jump عبر مدار ✓ **حقل معاكس** يلقيك للأرض ثم يعيدك ✓ ممران على السقف ✓ الختام: مدار ثلاثي، Double Jump عبر مدار، حفرة.

### Level 04 — DISTORTION (Brutal)
Double Jump عبر مدار ✓ **سلسلة قلب:** ثلاثة قلوب في الهواء بين Trap وألغام ✓ **Inverted Walls:** جدار من الأرض يجبرك على السقف، بوابة، جدار معلّق يجبرك على الأرض، وقفزات قصيرة تحتهما ✓ **Gravity Pit** يحملك فوق الفراغ ✓ ممران على السقف بأربع قفزات سريعة ✓ سلسلة Double Jump ✓ **الممر الدوّار:** ثلاثة قلوب في الهواء بين صخرة ومدار وشقّ، ثم Double Jump عبر مدار وعبر صخرة.

### Level 05 — THE HORRIFYING GALAXY (Brutal but fair)
1. **Ground Mastery** — ألغام، مدار، شقّ، Double Jump عبر مدار، Trap، مدار ثلاثي.
2. **Fast Gravity Flips** — أربعة قلوب في الهواء متتالية، بين كل اثنين Trap أو صخرة أو شقّ.
3. **Ground/Ceiling Dual Hazards** — شقّ، Flip Field فيه صخرة وDouble Jump عبر مدار على السقف، شقّ، ألغام مع صخرة.
4. **Long Chained Sequences** — Double Jump عبر مدار ← عبر صخرة ← قلب ← عبر صخرة ← قلب ← مدار ثلاثي.
5. **FINAL GRAVITY GAUNTLET (آخر 15%)** — Double Jump عبر مدار ← قلب في الهواء فوق Trap ← ممر تحت جدار بست قفزات قصيرة كل 0.42 ث (ألغام وTraps بالتناوب) ← قلب في الهواء فوق شوكتين ← Double Jump عبر مدار ← النهاية. **آخر 15%: 4.90 bit/s، وذروة 5.95 bit/s** — أصعب مقطع في World 03.

### الكيان (World 03)

## 11. Score، Shards، الموت والتقدم

- **Score** = 10 نقاط لكل Tile + **100** لكل Shard. الـShards المجمعة بعد آخر Checkpoint تعود لمكانها عند الموت.
- **تقدّم المستوى (%)** = (x اللاعب − x البداية) ÷ (x النهاية − x البداية)، بالمسافة فقط، بين 0 و100. يرتفع أثناء الجري فقط.
- **الموت:** تحطم → لوحة موت صغيرة أعلى الوسط (**ATTEMPT n**، Score، **BEST**، و`PROGRESS 60% - 25 = 35%`) → Fade → العودة جاريًا عند **آخر Checkpoint** (أو البداية)، بسرعة صفرية عموديًا، والقفزتان متاحتان، وكل العوائق في حالتها عند تلك اللحظة، والكاميرا عند اللاعب. عداد المحاولات يبدأ من جديد مع Restart أو مستوى جديد.
- **عقوبة الموت:** مؤشر التقدّم ينقص **25 نقطة** (ولا ينزل تحت 0%)، ثم لا يرتفع مجددًا إلا حين يتجاوز موضع اللاعب الفعلي القيمة المخفّضة. مثال: 60% → موت → 35%، والعودة عند Checkpoint 33%؛ المؤشر يبقى 35% حتى يتجاوزها اللاعب. عند خط النهاية: 100%.
- **النهاية:** لوحة نتيجة: LEVEL COMPLETE، Score، NEW BEST!، Shards (x / المجموع)، عدد المحاولات، و"**<اسم المستوى التالي> UNLOCKED**"، وزرّا **NEXT LEVEL** و**RETRY**.
- **بعد Level 05 في World 01:** العنوان **WORLD 01 COMPLETE** وسطر **WORLD 02 UNLOCKED**، وزر **NEXT** ينقل إلى World 02 (الألوان والخلفية والواجهة والكيان تتبدل معه). بعد ABSOLUTE ZERO: **WORLD 02 COMPLETE** و**WORLD 03 UNLOCKED** وزر **NEXT** إلى World 03. بعد THE HORRIFYING GALAXY: **WORLD 03 COMPLETE** بلا عالم تالٍ (لا World 04).
- **الفتح:** المستوى الأول من World 01 مفتوح دائمًا؛ إنهاء أي مستوى يفتح التالي؛ World 02 يُفتح بإنهاء World 01 كاملًا. **الحفظ** لكل معرّف مستوى (`w01_l01`…، `w02_l01`…): أفضل Score، أكثر Shards، والإنهاء.

## 12. الواجهة (UI)

```
┌──────────────────────────────────────────────────────────┐
│ 1,240                                     ◆ 12   [ ❚❚ ]  │  ← أثناء اللعب فقط
│                       ATTEMPT 3                          │  ← عند الموت فقط
│                   2,010  ·  BEST 5,830                    │
│                  (مساحة اللعب نظيفة)                      │
└──────────────────────────────────────────────────────────┘
```
- **شاشة البداية = اختيار المستوى:** تبويبا **WORLD 01 / WORLD 02** (الثاني مقفل حتى إنهاء الأول)، "WORLD 0N · اسم العالم"، خمس بطاقات (رقم، اسم، قفل للمغلق، معيّن للمنتهي، إطار مضيء للمختار)، ثم اسم المستوى ووصفه، "TAP TO START"، أفضل نتيجة، وسطر "WORLD 01 COMPLETE · WORLD 02 UNLOCKED" بعد إنهاء العالم. لمسة على بطاقة تختارها، ولمسة في أي مكان آخر تبدأ. الـHUD مخفي هنا.

- **Pause:** طبقة داكنة + RESUME / RESTART.
- **Mobile:** Landscape، Safe Area، زر Pause ≥ 64px، إيقاف تلقائي عند الخروج للخلفية. النصوص بالإنجليزية (العربية تحتاج خطًا مضمَّنًا → Localization لاحقًا).
